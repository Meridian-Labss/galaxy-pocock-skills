type: llm
criteria: >
  Where the document lists more than one parallel point (e.g. multiple risks,
  multiple rollout steps, multiple open questions), it uses an actual bullet
  or numbered list rather than a run of paragraphs, even when each paragraph
  opens with a bold label. A paragraph per point does not count as a list. A
  reader scanning only headings, first sentences, and bullet lists should be
  able to get every important point, including inside sections that explain
  reasoning or trade-offs, without reading a dense paragraph in full.
weight: 1
